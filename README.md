One funny line, 63 characters: "I named my houseplant Wi-Fi so I'd finally notice when it dies." An everyday truth (houseplants die unnoticed, a dead Wi-Fi is noticed at once) with the surprise saved for the very last words. Pure Python standard library; `main.py` writes the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
